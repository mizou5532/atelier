# Atelier v1 — plan de construction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un accueil privé, surtout pour ordinateur, qui montre tous les projets GitHub du propriétaire (regroupés, avec statut, avancement, étapes, liens), ses idées, ses projets endormis et ses quotas IA, et qui se met à jour tout seul.

**Architecture:** Un seul Worker Cloudflare sert l'interface React (fichiers statiques) et une API Hono sous `/api/*`, derrière Cloudflare Access et une vérification du jeton Access dans le Worker. Une base D1 garde ce que le propriétaire décide et une copie de ce que GitHub dit. Une minuterie toutes les 15 minutes lit GitHub (clé en lecture seule) et les fiches `ETAT.md`. Un petit script de barre d'état Claude Code envoie les quotas Claude.

**Tech Stack:** TypeScript, React 18 + Vite, Hono, Cloudflare Workers + D1 + Cron Triggers + Access, zod, `yaml`, vitest + `@cloudflare/vitest-pool-workers`, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-23-atelier-design.md` (à lire en entier avant de commencer). Maquette retenue : direction A, https://claude.ai/artifact/Ty9PkEvXW2hRNGBn8owqD6 (« A · Couleurs de projets »).

## Global Constraints

- Interface en français du Québec; heures sur 24 h, fuseau `America/Montreal`; virgule décimale; tutoiement.
- Valeur inconnue affichée « — » ou « À compléter », jamais 0.
- Atelier n'écrit jamais dans les dépôts GitHub; clé GitHub en lecture seule (Metadata + Contents read, All repositories).
- Aucun jeton ou connexion d'abonnement IA lu, stocké ou envoyé; aucun changement de compte automatique.
- Secrets : `.dev.vars` en local, `wrangler secret put` en ligne, secrets GitHub Actions; jamais dans Git ni dans le chat.
- Toute requête `/api/*` refusée (403) sans jeton Access valide; adresse `workers.dev` avec Access activé (même principe que `pistes/worker/acces.ts`).
- Conçu pour ordinateur (maquette 1440 × 900); une colonne sous 720 px de large.
- Apparence direction A : fond `#FFFFFF`, texte `#111827`, police Plus Jakarta Sans, coins 18–22 px, ombre `0 1px 2px rgba(17,24,39,0.04)`, une couleur par projet.
- Seuil « endormi » 30 jours (réglable); synchronisation toutes les 15 min (`*/15 * * * *`).
- Migrations D1 : jamais modifiées une fois appliquées; uniquement des ajouts.
- Commits en français, petits et vérifiés.

## Review Focus

- Un dépôt renommé sur GitHub reste rattaché au même projet (clé = identifiant GitHub) → test dans la tâche 6.
- Clé GitHub expirée ou GitHub en panne : bandeau clair, rien n'est effacé, dernières données affichées → test dans la tâche 6.
- `ETAT.md` mal formé (YAML cassé, `avancement: 140`, statut inconnu, accents/majuscules) : pastille « Fiche à vérifier », anciennes valeurs gardées → tests dans les tâches 4 et 6.
- Heure de réinitialisation passée sans nouveau chiffre → « réinitialisé, plein »; affichage correct au changement d'heure (heure de Montréal) → tests dans la tâche 10.
- Jeton de service (script des quotas) utilisé sur une autre route que `POST /api/quotas/claude`, ou requête sans jeton par `workers.dev` → 403 → tests dans la tâche 1.
